## **Description**

The DevLab I2C Push Button Module (MPN **UE0168**) is an I2C push button input module in the UNIT Electronics DevLab family. The product-specific board views and any released drawings are collected under `hardware/`.

### **Applications**

- Push button input in an I2C-based prototype.
- Evaluation of the module with a compatible host controller.
